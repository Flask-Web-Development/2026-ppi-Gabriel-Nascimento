## Como rodar os projetos ↓

### Tutorial Flask

> Acessar o caminho src/flask-tutorial
>
> Rodar o comando `flask --app flaskr init-db`
>
> Rodar o comando  `flask --app flaskr run`

### Controle de despesas

> Acessar o caminho src/Controle-despesas
> 
> Rodar o comando `flask --app app init-db`
>
> Rodar o comando `flask --app app run`

### Controle de despesas ORM

> Acessar o caminho src/Controle-despesas-ORM
>
> Rodar o comando `flask --app app init-db`
>
> Rodar o comando `flask --app app run`
